# C1 reproducibility package — local candidate

## Start

Use Python 3.12 with the scientific versions recorded by the experiments. Nothing
is installed automatically. Sources and existing requirements are retained below.
Run: .\Run-C1.ps1 -Action inspect -PythonExecutable <your-python>
For another machine copy paths.example.json to paths.local.json and edit the roots.
Relative paths resolve from this package folder; absolute paths are also accepted.
Local paths and data are excluded by .gitignore. Do NOT upload paths.local.json.

## Selected entrypoints

- inspect: file/directory existence; -VerifyHashes additionally hashes pinned files.
- compare: saved-prediction analysis for the 24 ML pipelines and two neural models,
  all three seeds and five common cases. No model inference, training or new tests.
- export-ml: copy receipt-verified frozen numeric tables. These are original E32
  outputs, not a claim that every old table or plot is used unchanged in the paper.
- plan-resnet / plan-inception: show the original pilot plan; no training.
- plot-comparison: set comparison_analysis to a completed compare output first.
  Use python_graphics and optional graphics_deps for a separate graphics environment.
  The launcher copies its CSV/JSON inputs to a new folder before creating plots.
  Inspect actual PDFs before manuscript use. No figure is generated by the builder.

Run an action with .\Run-C1.ps1 -Action compare -PythonExecutable <your-python>.
Default action is inspect. Results go to a new timestamped folder under output_root.
The launcher generates runtime configs by changing paths ONLY; source configs,
architecture, seeds, scaling, folds, noise identities and recorded run manifests
remain unchanged. Frozen comparator identity/parity checks are not disabled.

## Data and artifact contract

See data_requirements.json and DATA.md. No dataset, prediction array or checkpoint
is bundled by this builder. The existing ResNet reference CSV is copied only after
checking its pinned hash. Missing data are documented, never simulated or replaced.
No fake public URL/DOI or availability claim is generated.

## Source organization and limits

sources/e32 preserves the amended E32 tree and its pinned upstream hierarchy.
sources/resnet and sources/inceptiontime retain the selected configs/src/docs/tests
and comparative analysis/plot tools. selected_sources.csv records original SHA256.
Original machine-specific launchers are not active public entrypoints. Specialist
diagnostic sources are under reference/diagnostics: their historical launch scripts
  may still require dedicated path adapters and are not certified portable here.

The original distributed ML retraining pipeline depends on qualified hosts,
Prefect, the original simulation dataset and an external PyWavelets wheel. It is
retained as reference, NOT exposed as a working portable retraining command. Neural
training code remains present, but this launcher deliberately offers plans/analysis.
No retraining is needed to reproduce the saved-prediction comparator.
